# E-commerce Store

A personal full-stack e-commerce project built to gain practical experience in modern web development.

The project includes a React-based frontend and a Node.js backend, which will be developed as part of the project.

## Tech Stack

### Frontend
- React
- TypeScript
- Tailwind CSS
- Vite

### Backend
- Node.js
- Express.js

## Project Structure

The project is being developed with a separate frontend and backend architecture.

### Frontend
The frontend is being developed with React and TypeScript, with a focus on:

- Reusable React components
- Responsive user interface
- Component-based architecture
- Clean and maintainable code structure

### Backend
The backend will be developed using Node.js and Express.js and will provide the APIs and server-side functionality required by the e-commerce application.

## Project Status

🚧 **In Progress**

The frontend is currently under development.  
Backend development will be implemented as the project progresses.

## Purpose

This project is a personal learning project created to strengthen my practical skills in frontend and backend development and to apply what I have learned by building a complete e-commerce application.

## Getting Started

### Frontend

```bash
npm install
npm run dev
```
The frontend will be available at the local development URL provided by Vite.

### Backend

Backend setup and instructions will be added as the server-side implementation is developed.
